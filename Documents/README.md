# Справочные документы

Раньше в этой папке лежали PDF с текстами ГОСТов и методических материалов из
шаблона диссертации (~3.5 МБ). Чтобы репозиторий оставался лёгким, сами файлы
убраны из git — при необходимости их можно взять в репозитории исходного шаблона
[Russian-Phd-LaTeX-Dissertation-Template](https://github.com/AndreyAkinshin/Russian-Phd-LaTeX-Dissertation-Template/tree/master/Documents)
или найти по номерам стандартов:

| Файл (был в репозитории) | Документ |
|---|---|
| `GOST R 7.0.11-2011.pdf` | ГОСТ Р 7.0.11-2011. Диссертация и автореферат диссертации. Структура и правила оформление |
| `GOST R 7.0.5-2008.pdf` | ГОСТ Р 7.0.5-2008. Библиографическая ссылка |
| `GOST 7.1-2003.pdf` | ГОСТ 7.1-2003. Библиографическая запись. Библиографическое описание |
| `GOST 7.80-2000.pdf` | ГОСТ 7.80-2000. Библиографическая запись. Заголовок |
| `GOST 2.105-95.pdf` | ГОСТ 2.105-95. Общие требования к текстовым документам |
| `Def_positions.pdf` | Рекомендации диссертационного совета Томского ГУ по формулировкам защищаемых положений |
